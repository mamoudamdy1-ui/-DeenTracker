# 📚 تطبيق مذاكرتي - مساحتك الخاصة للدراسة والتركيز

تطبيق ويب تقدمي (PWA) متكامل مصمم خصيصاً للطلاب لتنظيم المذاكرة، إدارة المهام، مراجعة الفلاش كاردز (Spaced Repetition)، تدوين ملاحظات كورنيل الذكية، مؤقت البومودورو، ومتابعة التقدم الدراسي مع دعم **تعدد المستخدمين والخصوصية التامة لكل طالب على نفس الجهاز**.

---

## ✨ المميزات الرئيسية

- 👥 **دعم تعدد المستخدمين (Multi-User)**:
  - يمكن لأكثر من طالب (إخوة أو زملاء) استخدام التطبيق على نفس الجهاز أو المتصفح.
  - بيانات كل طالب (المواد، المهام، الكروت، الملاحظات، التسجيلات الصوتية، الدرجات، الإحصائيات) **معزولة ومستقلة تماماً** عن باقي الحسابات.
  - واجهة تسجيل دخول سهلة وسريعة تعرض قائمة الحسابات المحفوظة لاختيار الحساب بنقرة واحدة، مع إمكانية التبديل بين الحسابات أو إنشاء حساب جديد.
  - حماية كلمات المرور محلياً عبر تشفير قوي وعصري (`PBKDF2-SHA256`) عبر Web Crypto API بدون الحاجة إلى خوادم خارجية.

- ⏳ **مؤقت التركيز والبومودورو (Pomodoro Timer)**:
  - جلسات تركيز قابلة للتخصيص (15 إلى 90 دقيقة) مع فترات راحة قصيرة وطويلة.
  - شاشة ملء الشاشة (Zen Mode)، وميزة منع قفل الشاشة تلقائياً (Wake Lock API).
  - تشغيل صوت خلفية هادئ أو تلاوات قرآنية كريمة بصوت كبار القراء.
  - صندوق الأفكار المشتتة ("فكرة شتّتتك؟ اكتبها وكمّل").

- 🗂️ **كروت الفلاش كاردز الذكية (Flashcards & SRS)**:
  - خوارزمية التكرار المتباعد الذكية (صعب / متوسط / سهل) لتحقيق أعلى درجات الحفظ والاستيعاب.
  - استيراد سريع لعشرات الكروت دفعة واحدة (Bulk Import).
  - وضع العرض التلقائي الموقوت (Flashcard Presenter) لتقليب الكروت تلقائياً.
  - اختبار سريع متعدد الخيارات مولّد تلقائياً من كروتك.

- 🎯 **سجل الأخطاء ("أخطائي")**:
  - رصد تلقائي لأي كارت واجهت فيه صعوبة، مصنف حسب كل مادة، لتركيز مراجعتك على نقاط ضعفك قبل الامتحانات.

- 📝 **ملاحظات كورنيل (Cornell Notes)**:
  - مفكرة بأسلوب كورنيل العالمي (الكلمات المفتاحية والأسئلة | الشرح والتفاصيل | الخلاصة).
  - وضع الاختبار الذاتي (Cloze Deletion) لإخفاء الكلمات الهامة واختبار حفظك.
  - تحويل أي ملاحظة بضغطة زر إلى كارت مراجعة.

- 🕌 **مواقيت الصلاة بتوقيت مصر**:
  - حساب دقيق بالدقيقة لـ 13 مدينة مصرية بتوقيت الهيئة المصرية العامة للمساحة.
  - التوقف التلقائي لمؤقت المذاكرة أثناء وقت الأذان للتذكير بالصلاة.

- 🗓️ **الجدول الدراسي والترم**:
  - متابعة أسابيع الترم الأول والثاني، جدول الحصص والمحاضرات الثابت، وعدّ تنازلي للامتحانات.

- 📊 **الإحصائيات ونظام التحفيز**:
  - خريطة نشاط لـ 5 أسابيع (Study Heatmap)، ورسوم بيانية أسبوعية بالدقائق والمواد.
  - نقاط الخبرة (XP) وشارات إنجاز تتطور مع كل دقيقة مذاكرة وكل كارت يتم حفظه.

- 🔒 **الخصوصية والعمل دون إنترنت (Offline PWA)**:
  - التطبيق يعمل بالكامل دون الحاجة إلى اتصال دائم بالإنترنت.
  - إمكانية التثبيت كتطبيق مستقل على الهواتف (Android / iOS) وأجهزة الكمبيوتر.
  - تصدير واستيراد نسخة احتياطية خاصة بكل حساب.

## 🚀 طريقة النشر على GitHub و GitHub Pages

التطبيق مجهز بنسبة 100% للنشر والاستضافة المجانية المباشرة عبر **GitHub Pages**:

### الطريقة الأولى: النشر التلقائي عبر GitHub Actions (الأسهل والأفضل)

1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub (مثلاً باسم `mzakrti`).
2. ارفع كود المشروع إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "الإصدار الأول من تطبيق مذاكرتي"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/mzakrti.git
   git push -u origin main
   ```
3. توجه في GitHub إلى إعدادات المستودع **Settings** > ثم من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - في خانة **Source**، اختر **GitHub Actions**.
5. سيبدأ ملف العمل المرفق (`.github/workflows/deploy.yml`) بالبناء والنشر تلقائياً خلال دقيقة واحدة!
6. سيظهر لك رابط موقعك المباشر: `https://YOUR_USERNAME.github.io/mzakrti/` 🌟

## 💻 التشغيل والتطوير محلياً (Local Development)

إذا أردت تشغيل المشروع أو التعديل عليه على جهازك:

1. تأكد من تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
2. ثبّت الحزم:
   ```bash
   npm install
   ```
3. شغّل خادم التطوير:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. لبناء النسخة النهائية للإنتاج:
   ```bash
   npm run build
   ```
   سيتم توليد ملفات الموقع الجاهزة للنشر داخل مجلد `dist/`.
